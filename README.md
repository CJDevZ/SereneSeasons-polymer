## Polymer Patch for Serene Seasons

This is a patch for <a href=https://modrinth.com/mod/serene-seasons><img src="https://cdn.modrinth.com/data/e0bNACJD/f8b292ea53e0a0ea908570defddc48673d16d7d6.png" width="16" height="16" alt="Serene Seasons Icon"></a> [Serene Seasons](https://modrinth.com/mod/serene-seasons), making it work fully server side, with nearly all of its functionality intact.

Serene Seasons is required and not included within this mod.

This mod requires a server resource pack, about which setup you can read here:
https://polymer.pb4.eu/latest/user/resource-pack-hosting/

You can read more about [Serene Seasons on its Modrinth page!](https://modrinth.com/mod/serene-seasons)
